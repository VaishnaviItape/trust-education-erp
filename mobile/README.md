# Mobile Application (`mobile/`)

Built with **React Native and Expo** (TypeScript).

## Single Codebase for Both Platforms & Roles
By using React Native with Expo, you write one code in TypeScript/JavaScript, and it works natively on both **Android** and **iOS**. You can also run it right on your physical smartphone using the free **Expo Go** app during your demo to the Trust management!

## User Portals in App
1. **Parents Portal (School):**
   - Attendance percentage & calendar.
   - Pending fee notifications & UPI pay button.
   - Daily homework diary & study notes.
   - Interactive Live Bus Tracking map.
   - School activities & event photo gallery.

2. **Students Portal (College of Hotel Management):**
   - Semester schedule & lecture timetable.
   - Practical Kitchen & F&B Lab batch rosters.
   - Industrial Training (Internship) digital logbook.
   - Digital student ID card with QR Code.

3. **Faculty / Teacher Portal:**
   - 30-second mobile attendance marker.
   - Quick homework photo upload.

4. **Bus Driver Mode:**
   - One-tap "Start Trip / Stop Trip" with live background GPS broadcaster.
